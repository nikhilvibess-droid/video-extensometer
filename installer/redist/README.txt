Place the Microsoft Visual C++ 2015-2022 Redistributable (x64) installer here before compiling the setup package.

Download from Microsoft:
https://aka.ms/vs/17/release/vc_redist.x64.exe

Rename the downloaded file to:
vc_redist.x64.exe

The Inno Setup script installs this runtime automatically when it is not already present on the target PC.
