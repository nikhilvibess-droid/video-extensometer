================================================================================
THE CRITICAL FIX (One Line of Code)
================================================================================

FILE: camera.py
LINE: 108
CHANGE: frame = frame.copy()

THIS ONE LINE FIXES THE ENTIRE CRASH.

Why: PySpin returns readonly references to managed memory. The .copy() method
allocates new writable numpy memory, which is compatible with all OpenCV
drawing operations (cv2.circle, cv2.line, cv2.putText).
